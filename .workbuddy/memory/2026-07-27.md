## Plane REST API gotchas (reusable — cost ~20 calls to discover)
- API base `https://api.plane.so/api/v1`. Header `X-Api-Key: plane_api_...`.
- `GET /workspaces/{slug}/` returns 401 even with a valid token (route uses session auth); use `/workspaces/{slug}/projects/` instead, which authenticates fine.
- Create project: `POST /workspaces/{slug}/projects/` (name, identifier, description, network, icon_prop, *module_view/cycle_view/page_view/issue_views_view/intake_view*).
- Create cycle: `POST /projects/{pid}/cycles/` — MUST include `project_id` in the JSON body (URL alone -> 400 "Project ID is required").
- Create issue (work-item): `POST /projects/{pid}/work-items/`. On create ONLY `name`/`description_html`/`priority`/`assignees` are applied. `state_id`, `label_ids`, `cycle_id` in the body are SILENTLY IGNORED.
- To set state + labels: `PATCH /work-items/{id}/` with field names `state` (not `state_id`) and `labels` (not `label_ids`), e.g. `{"state":"<id>","labels":["<id>"]}`.
- To add to a cycle: `POST /cycles/{cid}/cycle-issues/` with `{"issues":["<work_item_id>"]}` (NOT `issue_ids`/`work_item_ids` -> 400 MISSING_WORK_ITEMS).
- Rate limit: 60 req/min per API key.
- Credentials used (do NOT store the raw token in memory): PLANE_API_KEY, PLANE_WORKSPACE_SLUG=hspace, PLANE_BASE_URL=https://app.plane.so/. Provided by user for this task; recommend rotating after use.
