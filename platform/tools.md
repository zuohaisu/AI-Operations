# Tool Use

| Capability | Use when | Constraint |
|---|---|---|
| File read/write | code, docs, generation | Read before write |
| Shell / terminal | build, test, git | No irreversible ops; background long jobs |
| Web search | versions, prices, current state, anything post-cutoff | Search, do not recall |
| Web fetch | reading a known doc | Primary source preferred |
| Code search | locating symbols/files | Exact first, then widen |

Rule: if a capability exists and would raise answer quality, use it.
Guessing when a tool could have verified is a core/04 violation.
